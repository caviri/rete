Wikidata-100MB

one ~12M-triple graph, queried two ways — both lazily over HTTP range, nothing downloaded whole ← playground

The same Wikidata slice lives on Hugging Face as a .rete graph and as columnar .parquet entity-tables (plus DuckDB/SQLite). This page queries both in your browser fetching only the bytes each query touches: the graph via rete's sparql_url (a Web Worker doing range reads), the tables via DuckDB-WASM's httpfs over the remote Parquet. Compare the same questions across the graph and the table model.

Graph · rete sparql_url (lazy range)

SPARQL over wikidata.rete. Bound subjects/predicates fetch only the tiles holding them. Returns recovered datatypes (e.g. geo:wktLiteral).

Tables · DuckDB-WASM over remote Parquet (httpfs)

One Parquet table per entity type. Pick a type (from _manifest.parquet), or write SQL. DuckDB fetches only the row groups/columns it needs.
