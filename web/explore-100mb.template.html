Graph - SPARQL

Lazy SPARQL over the .rete graph.

Remote data isn't reachable from this browser. The bundle is hosted on a Hugging Face bucket, whose resolve endpoint returns 405 to cross-origin browser range requests — so the lazy Graph, Tables and SQLite backends can't fetch it here. (The rete CLI works fine: it isn't subject to CORS.) To run these in the browser, host the bundle on a CORS-enabled direct server (S3/R2/GCS) or same-origin. You can still browse the example queries below.
