The same Wikidata slice lives on Hugging Face as a .rete graph, columnar .parquet entity-tables, a .duckdb database, and a .sqlite database. This page queries all of them in your browser, fetching only the bytes each query touches — rete via sparql_url (range reads in a Worker), Parquet/DuckDB via DuckDB-WASM (httpfs), SQLite via sql.js-httpvfs. Click a question to load the analogous query on every side. Tables in this slice are named by Q-id: Q5=human, Q16521=taxon, Q11424=film.
