Query playground

100% client-side. This single page embeds the WASM engine and the demo datasets (base64) — no server, no app-load network requests. Works offline from file://. It hands a .rete file's bytes to WebAssembly and runs the dictionary, permutation indexes, SPARQL and zstd decode entirely in your browser. Follow the numbered steps below.

2 Query — SELECT / ASK / CONSTRUCT

Example query families — grouped easy → hard: basics (one pattern, ASK, count) → grouping, filters & dates → multi-way joins, property paths, aggregates & CONSTRUCT. Click any chip to load it, then Run.

3 Reachability — transitive reach over one relation

Transitive reach over a single relation: from each seed, every node reachable by following that one predicate repeatedly (the relation's transitive closure from the seed).

  • Forward = "what does the seed reach?"; reverse (--reverse / the checkbox) = "who reaches the seed?" — i.e. impact analysis (e.g. "which packages transitively depend on this vulnerable one?").
  • Single-relation — one predicate at a time. Multi-seed — comma-separated seeds run together.
This offline build runs reach single-threaded. For real in-browser multicore over big graphs / many seeds, open the experimental threaded playground — it runs reach on a Web-Worker pool that works on any static server (no special headers) (see Parallel in the browser). Natively, rete reach --parallel does ~14–15× (Benchmarks).
