rete · interactive query playground

No database server. This page fetches a single .rete file and runs everything — dictionary, permutation indexes, SPARQL, zstd decode — in WebAssembly. It shows the ontology overview first (the semantic coarse graph), then lets you run SELECT / ASK / CONSTRUCT and render the result as a table, Turtle, or JSON-LD.

Progressive load — fetch the overview over HTTP ranges, skipping the index

Fetches only the header, dictionary, and pyramid summary via HTTP Range requests — the (large) triple index is never downloaded. Needs a range-capable host (the bundled scripts/range_server.py qualifies).

Query — SELECT / ASK / CONSTRUCT, runs entirely in your browser

Reachability — multi-source transitive reach over one relation, in your browser

The browser engine is single-threaded; reach runs serially here. The native CLI's rete reach --parallel fans out one task per seed (~14–15× on many cores) — see the Benchmarks.
