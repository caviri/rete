rete · parallel reachability (experimental)

⚠ Experimental. This page parallelizes transitive reachability across a pool of Web Workers — each worker is its own WASM instance running the serial reach over a slice of the seeds (message passing, no SharedArrayBuffer). So it works on any plain static server (no COOP/COEP needed), using the normal web/pkg build. The stable single-file playground is docs/playground.html; the native multicore path is rete reach --parallel (Benchmarks).
