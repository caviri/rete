yasgui·wasm
A Yasgui-style SPARQL IDE where the endpoint is a .rete file: paste a link (queried lazily over HTTP range — only the bytes your query touches are fetched) or drop a local file. The engine is WebAssembly inside this page — no server, no upload.
.rete
UI after Yasgui (Triply) — engine: rete, a cloud-native range-queryable RDF file format, compiled to WebAssembly and inlined into this single HTML file. Everything runs client-side: your queries never leave the machine — for remote files the network sees only HTTP range requests for raw bytes. Uploaded files are read in memory and never sent anywhere.
