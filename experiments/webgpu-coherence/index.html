Environment

Kernel A — cross-graph fuzzy disjointness / disagreement

Two graphs each assert a fuzzy membership μ in [0,1] over the same N aligned entities. Conflict degree = Gödel t-norm min(μG1, μG2); we count entities whose conflict exceeds τ. Low arithmetic intensity — one min + one compare per element, so this is the shape where PCIe upload and readback overhead should dominate.

Kernel B — fuzzy transitive-closure contradiction (max-min semiring)

Sparse max-min SpMV in CSR, iterated k times GPU-resident (ping-pong buffers, one upload, one readback): yi = max(xi, maxj∈adj(i) min(wij, xj)). This is the GraphBLAS primitive behind fuzzy reachability — "G1 says x⇒z at degree 0.8" — which you then test against G2's reverse assertions. High arithmetic intensity, data stays resident across iterations.
