What this is

A .rete file is a whole RDF graph in one immutable, range-queryable file. This page treats it the way an archive tool treats a .zip: it opens the table of contents, lets you walk into folders, and extracts what you select as real files — CSV, JSON, N-Triples.

RDF is a graph, not a tree, so there is no single honest folder hierarchy. There are several, and you switch between them: Types (classes as folders), Namespace (the IRI's own path), Predicates (one table per relation), Graphs (named graphs as volumes), and Sections (the actual bytes on disk).

Experiment. The tree is lazy and paginated because a class can hold fifty million instances; the counter in the footer shows exactly how many bytes browsing cost you.
