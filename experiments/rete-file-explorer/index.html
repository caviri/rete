What this is

A .rete file is a whole RDF graph in one immutable, range-queryable file. This page treats it the way an archive tool treats a .zip: it opens the table of contents, lets you walk into folders, and extracts what you select as real files — CSV, JSON, N-Triples.

RDF is a graph, not a tree, so there is no single honest folder hierarchy. There are several, and you switch between them: Types (classes as folders), Namespace (the IRI's own path), Predicates (one table per relation), Graphs (named graphs as volumes), and Sections (the actual bytes on disk). Graph draws what you select — the schema, a class, an entity and its links — as the same interactive graph the rete extension shows in Claude.

A catalog is a JSON list of .rete links that anyone can publish. Subscribe to one by pasting its link; the pictures are drawn from each file's own card (its classes and how they connect), read with two small requests.

Experiment. The tree is lazy and paginated because a class can hold fifty million instances; the counter in the footer shows exactly how many bytes browsing cost you.
