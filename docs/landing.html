rete packs your triples and the indexes that find them into a single .rete file. Put it on object storage, GitHub Pages, Zenodo or any web server. Each SPARQL query reads only the parts of the file it needs, so there is no database to run.

How it works

Build once, host it, query from anywhere

  1. 1

    Build

    Turn Turtle, N-Triples, N-Quads or Jelly into one .rete file. It holds the triples, the indexes that find them and a Dataset Card that says what is inside.

    rete build data.ttl -o data.rete --card
  2. 2

    Host

    Upload the file anywhere that serves byte ranges: object storage, GitHub Pages, Zenodo, your own web server. There is no database to run or keep up.

    curl -r 0-1023 https://…/data.rete   # 206 Partial Content
  3. 3

    Query

    A client opens the file over HTTP, reads the header, then fetches only the dictionary chunks and index tiles the query touches. Selective queries stay small; a scan over everything still has to read everything.

    rete sparql-url https://…/data.rete "SELECT …"

Use it

The same file, from wherever you work

Every client below asks the jazz graph from the demo the same question.

# the CLI ships as a Docker image; see Install for the alias
rete sparql-url https://data.graphplaza.com/linked-jazz/linked-jazz.rete \
  "PREFIX foaf: <http://xmlns.com/foaf/0.1/>
   SELECT ?name WHERE { ?p foaf:name ?name } LIMIT 5"
# pip install rete-graph
import rete_graph as rete

g = rete.open("https://data.graphplaza.com/linked-jazz/linked-jazz.rete")
rows = g.query("""PREFIX foaf: <http://xmlns.com/foaf/0.1/>
    SELECT ?name WHERE { ?p foaf:name ?name } LIMIT 5""")
for row in rows:
    print(row["name"].value)
// npm install rete-graph   (Node, or a worker in the browser)
import { open } from "rete-graph";

const g = await open("https://data.graphplaza.com/linked-jazz/linked-jazz.rete");
const rows = g.query(`PREFIX foaf: <http://xmlns.com/foaf/0.1/>
  SELECT ?name WHERE { ?p foaf:name ?name } LIMIT 5`);
for (const row of rows) console.log(row.name.value);
# remotes::install_github("caviri/rete", subdir = "clients/r")
library(rete)

g <- rete_open("https://data.graphplaza.com/linked-jazz/linked-jazz.rete")
rete_query(g, "PREFIX foaf: <http://xmlns.com/foaf/0.1/>
  SELECT ?name WHERE { ?p foaf:name ?name } LIMIT 5")
# install rete.mcpb in Claude Desktop, then ask in plain words:

Support

Help keep rete free and open

rete is a project by h4ck1ng.science. The engine, the file format and every client are open source under the Apache 2.0 license, and the public graphs on this page are free for anyone to query. Support keeps it that way.

Where support goes

🗄️ Hosting the graphs The catalog at data.graphplaza.com serves dozens of graphs, some over 100 GB, to anyone who asks for a byte range.
⚙️ Building new graphs Turning a large open dataset into a .rete file can take days of compute and a lot of memory.
⏳ Time Work on the engine, the file format, the clients and these docs.
