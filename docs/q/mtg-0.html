The query

PREFIX mtg: <https://w3id.org/rete/mtg#> PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#> SELECT ?type (COUNT(?c) AS ?cards) WHERE { ?c a mtg:Card ; a ?t . ?t rdfs:subClassOf mtg:Card ; rdfs:label ?type . } GROUP BY ?type ORDER BY DESC(?cards)
