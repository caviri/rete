The query

PREFIX ncit: <http://ncitt.ncit.nih.gov/> SELECT ?diagnosis (COUNT(?s) AS ?n) (AVG(?age) AS ?meanAge) WHERE { ?s ncit:diagnosis ?diagnosis ; ncit:age ?age . } GROUP BY ?diagnosis ORDER BY DESC(?n)
