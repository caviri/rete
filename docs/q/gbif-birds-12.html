The query

PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#> PREFIX dwc: <http://rs.tdwg.org/dwc/terms/> PREFIX v: <https://w3id.org/rete/gbif/vocab#> SELECT ?genus (COUNT(?sp) AS ?n) WHERE { ?sp dwc:taxonRank "species" ; rdfs:subClassOf ?g . ?g rdfs:label ?genus ; dwc:taxonRank "genus" . } GROUP BY ?genus ORDER BY DESC(?n) LIMIT 25
