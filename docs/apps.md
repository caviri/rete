# Apps and experiments

These applications show different things you can build around graph data.
Some query `.rete` files directly; others display snapshots derived from a
graph. Each guide explains the data source, how to try it and its limitations.

## Start with a complete example

Try the [Playground](playground-guide.md) for a general-purpose query interface,
the [Historical atlas](atlas.md) for spatial and time-based questions, or
[JupyterLite](jupyterlite-guide.md) for a programmable Python workflow.
The [worked examples](recipes.md) explain how to apply these ideas yourself.
