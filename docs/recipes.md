# Worked examples

These examples show a complete task, with enough context to adapt it to your
own data. Start with one that matches the outcome you want.

## Build, query and share

**[Publish a dependency graph](scenario.md).** Build a software bill of
materials, ask which packages depend on a library, and query the published
file. This is a small end-to-end example of the file-and-URL workflow.

**[Build a graph in Python](python-build-tutorial.md).** Create RDF from code,
add metadata, build a file and inspect it. The
[browser notebooks](jupyterlite-guide.md) let you try the workflow without
setting up Python locally.

## Explore relationships

**[Historical atlas](atlas.md).** Ask a spatial question, inspect it on a map
and change the time. It shows why geometry and dates are useful alongside
graph relationships.

**[Graph analysis](graph-algorithms.md).** Extract the relationships relevant
to your question, compute with a Python library and save derived results.
For narrower tasks, try [topic labels](topic-modeling.md) or
[multi-criteria communities](multi-criteria.md).

**[JavaScript visualization](jslab-guide.md).** Edit a query and see its
result beside your code. For a language-model workflow, try the
[agent framework recipes](agent-frameworks.md).

Other visualizations and domain-specific demonstrations are collected in
[Apps and experiments](apps.md).
