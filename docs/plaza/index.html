Graphs that describe themselves

A gallery of .rete knowledge-graph files. Each file carries its own card, and this page reads every card live from the file. Open any graph and query it with SPARQL in your browser, without downloading it.

/

How it works

  1. A file with its own card

    A .rete file embeds a description of itself: counts, classes, properties, vocabularies, licence and example queries.

  2. Two range requests

    This page asks the host for the file header, then for the card. The graph itself is never downloaded.

  3. Query it where it lives

    Open a dataset and run SPARQL in the browser. Only the bytes a query needs are fetched.

For agents

This page registers WebMCP tools for browser agents that support document.modelContext: search the datasets, read a card, and filter the view. Querying happens on a dataset page.

The tools run in your tab and call the same functions the page uses. Nothing is sent to a server.

await plaza.ready
plaza.search({ query: "chemistry", sort: "triples" })
await plaza.card("chemotion")
plaza.applyView({ filters: { vocab: ["OWL"] } })
