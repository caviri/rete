Open source · RDF · SPARQL · MCP

Your RDF graphs in one place. Query them here, or from your agent.

Query them from a browser a browser, Python, JavaScript, R, Java, the command line or Claude

Each graph is a single .rete file with its indexes inside. A SPARQL query reads only the bytes it needs, so there is no database to run. Pick a graph, ask it a question, or give your agent the address.
